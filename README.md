# HelloWorldLab

A very simple Android "Hello World" app built with Kotlin and Android Studio.

## What it does

The app has 3 basic UI elements:

- A **text field** where the user types their name
- A **"Click Me" button**
- A **label** that displays "Hello World!" by default

When the button is tapped, the label updates to greet the user by the name they entered (e.g. "Hi, Hamza").

## Tech stack

- Kotlin
- AndroidX / ConstraintLayout
- Gradle build system

## How to run the app:

1. Open the project in Android Studio.
2. Let Gradle sync.
3. Run the app on an emulator or physical device.
